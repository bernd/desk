# desk (Go rewrite)

This is a Go rewrite of [desk](https://github.com/jamesob/desk), a lightweight workspace manager for the shell.

## What's Changed

This version is rewritten in Go using:
- **[Cobra](https://github.com/spf13/cobra)** for CLI framework
- **[sh/v3](https://github.com/mvdan/sh)** for robust bash/POSIX shell script parsing
- **Single binary** with no runtime dependencies

## Why Go?

- **Performance**: Faster startup and execution
- **Single binary**: No bash dependency, easy to distribute
- **Better parsing**: Uses proper AST parsing for shell scripts instead of regex
- **Cross-platform**: Easy to build for Linux, macOS, Windows (WSL)
- **Maintainability**: Strongly typed, easier to test and extend

## Building

```bash
go build -o desk
```

Or install directly:

```bash
go install github.com/bernd/desk@latest
```

## Installation

After building, install the binary:

```bash
sudo cp desk /usr/local/bin/desk
```

Then initialize:

```bash
desk init
```

## Features

All original desk features are supported:

- `desk init` - Initialize configuration
- `desk list` / `desk ls` - List all desks
- `desk go <name>` / `desk . <name>` - Activate a desk
- `desk run <name> <cmd>` - Run command in desk context
- `desk edit <name>` - Edit a deskfile
- `desk` - Show current desk
- `desk version` - Show version
- `desk completion <shell>` - Generate shell completions

### Shell Completions

Generate completions for your shell:

```bash
# Bash
desk completion bash > /etc/bash_completion.d/desk

# Zsh
desk completion zsh > "${fpath[1]}/_desk"

# Fish
desk completion fish > ~/.config/fish/completions/desk.fish
```

## Compatibility

The Go version maintains full compatibility with existing deskfiles (both `.sh` and `.fish`).

### Known Differences

1. **Error messages**: Slightly different formatting
2. **Performance**: Faster parsing and startup
3. **Completions**: Generated by Cobra (slightly different format but functionally equivalent)

## Testing

Run the original test suite:

```bash
# Set up test environment
ln -s $PWD/examples ~/.desk/desks

# Run tests with the Go binary
export PATH=$PWD:$PATH
bash test/run_tests.sh
```

